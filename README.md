# Chasing Horizon

## Overview

I built this project in C with raylib.
The game will use a 1D Perlin noise generator to generate obstacles.

The game itself however isn't the main project, I will be making a project related to
deep Q-Learning to showcase my skills and that project would build on top of this one.

The assets I have used are from _Merakintsugi_ [here](https://merakintsugi.itch.io/platformer-character-pack)
